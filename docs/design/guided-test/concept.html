Changing the base from here

The app will tell the base radio to switch to Long Fast, then switch your radio to match. The base restarts to do it.

What can go wrong: if the base restarts on a setting your radio can't reach from here, you'll have to walk to the base and fix it in Radio Setup. The base is 38 m away right now.

Guided test, clickable concept

Four screens: Ask → Plan → Run → Result. Pick a chip on the first screen; the plan and every step change with it. Every number is a sample. Design notes in README.md beside this file.

JUMP TO
RULES ON SHOW

One job per screen, one 56 px key. Mono orange captions, B612 everywhere, hairlines not shadows. The app never asks what it can work out: map, session names, rigs, ping interval, beacon. Fairness built in: ghost route, route match, same start point, base untouched between variants.

Remote base changes exist only on Meshtastic, only after the base was given the mobile radio's key over Bluetooth in Radio Setup, and only after the risk sheet. On MeshCore the same step says "walk to the base; the app connects over Bluetooth".

Result copy follows the never-null rule: what was proved, one number with margin per side, one next step.

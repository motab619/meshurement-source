Support

Meshurement™ support

Meshurement™ measures how far your LoRa mesh nodes really reach. Leave one node at home as the base, take the other with you, connected to your iPhone over Bluetooth, and the app records signal strength with your GPS position and draws it on a map.

Questions, bugs or ideas? Email us:

support@meshurement.com

Please include what you were doing, what happened, your iPhone and iOS version, and your radio models and firmware.

Questions

What do I need?

An iPhone and two LoRa mesh nodes of the same kind (Bluetooth radios like a Heltec V3 or a T1000-E): one stays at the base and one goes with you. One node is not enough, because the app measures the link between the two.

Allow Bluetooth and location for the app. iOS asks for Bluetooth the first time you connect a radio, and for location and notifications when you start your first session.

Which nodes work?

Meshtastic® nodes (firmware 2.5 or newer) and MeshCore companion nodes over Bluetooth. Both nodes must run the same kind of firmware. Both kinds work in the free app; you don't need Pro for either.

What's different between Meshtastic® and MeshCore nodes?

Most of the app works the same with both: maps, sessions, out-of-range alerts, backups, guided tests and the Field Report. Both are free. The differences come from how each firmware works.

Checking the link. With Meshtastic®, the app sends the base a private message and the base answers, so you see how well your node hears the base. With MeshCore, the app sends a link check (a trace) that comes back with the signal in both directions, so you also see how well the base hears you.

The base beacon. A Meshtastic® base sends a beacon on its own every so often, and the app notices the ones it missed. A MeshCore base sends nothing on its own: your node checks on the base at the beacon interval instead, and nothing on the base is changed for it.

Node Setup. Meshtastic® nodes restart after Node Setup and swap security keys. MeshCore nodes don't restart and need no key swap, but the base has to sit on one of the frequencies MeshCore allows for it (433.000, 869.495 or 918.000 MHz); the app fills in the right one for your band.

Range settings. Meshtastic® nodes use its named presets (Long Fast, Medium Fast and so on). MeshCore nodes use a list of range settings taken from the MeshCore community presets, fastest first.

Changing the base from a distance. Only Meshtastic® nodes can be changed over the mesh (Change the base from here, a Pro feature). MeshCore companion nodes can't be changed remotely, so you walk to the base and change it over Bluetooth.

What changed with Meshtastic® firmware 2.8?

No more Range Test. Firmware 2.8 leaves out the Range Test module (2.7.26 already lacks it on classic ESP32 boards). Older firmware uses Range Test as the base beacon; on 2.8 the base sends its device telemetry as the beacon instead. Node Setup picks the right one for your firmware, so you don't have to.

A slower beacon. A telemetry beacon goes out at most once a minute, because that is how often the firmware's telemetry runs. Range Test could go faster. The app's pings fill in between beacons either way.

After you upgrade a node to 2.8. The upgrade gives the node a new node number, switches its telemetry off, and on ESP32 boards (like the Heltec V3) clears its Bluetooth pairing. So after upgrading: in iOS Settings, Bluetooth, tap ⓘ next to the node and Forget This Device, connect it again, and run Node Setup on both nodes again. Node Setup turns telemetry back on and teaches the app the new numbers. Skip 2.8.0, which was withdrawn; use 2.8.1 or newer.

Newer range settings. 2.8 adds Medium Turbo, which the app offers on nodes running 2.8 or newer. Older firmware would quietly run it as Long Fast, so the app doesn't offer it there.

Security keys (2.7.19 and newer). A node won't send a private message to a node whose key it doesn't have. Node Setup gives each node the other's key, and the app puts it back on its own if it goes missing, for example after you clear a node's node list.

Will my tests go out on the public mesh?

No. Settings, Node Setup puts both nodes on a private test channel with its own random key, and the app refuses to start a session while a node is on the public channel. Your test traffic stays between your two nodes.

How do I put a node back to its original settings?

Node Setup saves a backup of each node before it changes anything, and keeps that first backup for good. Connect the node, open Settings, Node backups, and tap "Put this node back the way it was".

Can't connect to a radio?

A radio accepts only one Bluetooth app at a time. Force-quit the official Meshtastic app or the MeshCore app (and any other app using the radio), then try again. Radios without a screen usually use the pairing code 123456. Radios with a screen show a code to type in when iOS asks.

No out-of-range alerts?

Allow notifications for the app in iOS Settings. Alerts fire when you have been out of range of the base, when you are back, and when the phone loses its Bluetooth link to your radio.

How do I restore my Pro purchase?

Open Settings, About, tap the Pro row, then tap Restore Purchases. Use the same Apple ID you bought Pro with. Subscriptions are managed in iOS Settings under your name, Subscriptions.

How do I join the beta?

The beta runs on Apple's TestFlight. Sign up at beta.plateaunerd.com, then install TestFlight from the App Store and accept the invite. Beta testers can send feedback straight from TestFlight.

Is my data private?

Your recordings stay on your phone. The app has no ads, analytics or tracking. Read the privacy policy for the few things that can go online, each of which you control.

Accessibility

We want this website to work for everyone, including people who use screen readers, keyboard navigation, zoom or larger text. It aims to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA. If anything on the site is hard to use, email support@meshurement.com and we will fix it or get you the information another way.

Diagnostics log

If something goes wrong, Settings, About, Share diagnostics log lets you send us the app's recent connection and session log. It stays on your phone unless you share it.
